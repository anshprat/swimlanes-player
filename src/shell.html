    swimlanes.io syntax

    • A -> B: text, also --> ->> -x <-> =>, B <- A, and ->< for an automatic reply; the : is required
    • note A, B: text or todo: text; the lines below it continue it
    • _: -: --: =: dividers, ...: text delay
    • if: else: group: end
    • title: autonumber alias A: Name // comment # comment
    • order: A, B puts A and B first, then the rest
    • Lane names ignore case and keep their first spelling
    • **bold** _italic_ ~~strike~~ `code`

    Player lines and keys

    • // explain: text explains the message above
    • // state Lane: text sets what a lane holds after the message above
    • // phase: name starts a phase; dividers make phases too
    • swimlanes.io ignores these lines, so the diagram stays valid there
    • Click a row or its number to jump to it; ← → step, space plays, F full screen
    • Drag the divider to resize the editor; double-click it to reset
